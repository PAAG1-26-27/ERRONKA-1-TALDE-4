# Erronka1 - Jokuak

Proyecto Java con Maven para trabajar en Apache NetBeans.

## Abrir y ejecutar

1. Descargar el repositorio y descomprimirlo, o clonarlo con Git.
2. En NetBeans, seleccionar Archivo > Abrir proyecto y elegir la carpeta que contiene pom.xml.
3. Usar un JDK compatible con Java 26 (versión configurada en pom.xml).
4. Ejecutar el proyecto. La clase principal es Jokuen_menua.Jokoak_MENUA.

## Trabajo en grupo

Subir los cambios en src, pom.xml y los demás archivos del proyecto. La carpeta target se genera al compilar y está excluida mediante .gitignore. Los archivos de partidas guardadas también están excluidos.

Antes de empezar a trabajar, actualizar el repositorio con los cambios de los compañeros. Al terminar, guardar los cambios mediante commit y push.

Si se sube mediante la web de GitHub, seleccionar src, pom.xml, README.md y .gitignore; no seleccionar target. La web no aplica automáticamente las exclusiones de .gitignore al cargar archivos.
