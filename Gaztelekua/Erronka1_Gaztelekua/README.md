# Erronka1 Gaztelekua

Proyecto Java con Maven para Apache NetBeans.

1. Clona el repositorio o descarga y descomprime su ZIP.
2. En NetBeans, elige **Archivo > Abrir proyecto** y selecciona la carpeta que contiene `pom.xml`.
3. Configura un JDK 26 en NetBeans, tal como indica `pom.xml`.
4. Ejecuta el proyecto. Si NetBeans te pide la clase principal, elige `Gaztelekua.Menua`.

Maven crea la carpeta `target/` al compilar. Git la excluye mediante `.gitignore`.
